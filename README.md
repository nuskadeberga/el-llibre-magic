# El llibre màgic de la Sibil·la i en Ponç Hug

Web infantil amb el conte **La gran aventura de la Nyicris** i quatre cançons.

## Publicar-la a GitHub Pages

1. Crea un repositori nou a GitHub.
2. Puja **tot el contingut d'aquesta carpeta**, mantenint les carpetes `assets/pages` i `assets/audio`.
3. Al repositori, entra a **Settings → Pages**.
4. A **Build and deployment**, tria **Deploy from a branch**.
5. Selecciona la branca `main`, la carpeta `/ (root)` i prem **Save**.
6. Al cap d'uns minuts, GitHub mostrarà l'adreça pública de la web.

No cal instal·lar res ni executar cap programa. La web és estàtica i funciona en mòbil, tauleta i ordinador.
